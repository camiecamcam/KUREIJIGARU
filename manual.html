Welcome Open review app

QUICK REFERENCE

Review and rename PDFs

Kureijigaru reads document text and scans pages when needed to suggest a primary name. You review every suggestion; the app never renames a file without your approval.

01 / LOAD FILES

Select Folder or Open PDFs?

Select Folder

Choose the folder containing your PDFs. In a supported browser on localhost or HTTPS, grant read and write access. The app can then rename the original file in that folder.

Open PDFs

Choose one or more PDF files to review. This grants read access only. Approve & Download saves a renamed copy; it does not change the original.

For direct in-place renaming, start the app with start-local-app.bat, open it in Chrome or Edge, then use Select Folder. Keep the launcher window open.

02 / REVIEW

Check the suggestion

Select a PDF in the left list. The center preview shows its pages; use Previous and Next to move through the document and the plus/minus controls to zoom.

The primary-name field contains the current suggestion. OCR and text extraction can be imperfect, especially on scans and handwriting, so verify the name against the document before approving.

Use search to find a filename or name. The filters narrow the list to all documents, items needing review, approved items, handwriting, or failures.

03 / NAME ACTIONS

What each action does

Approve & Rename
Renames the selected original PDF in the chosen folder. If that name already exists, a numbered suffix is added. This cannot be undone outside the app.
Edit & Rename
Accepts the text currently in the primary-name field as your reviewed name. It does not rename the file yet; use Approve & Rename afterward.
Skip
Marks this item skipped and keeps its filename unchanged.
Review Later
Marks the item for another look without renaming it.
Undo Last Rename
Restores the most recently renamed PDF to its previous filename during the current session.

04 / STATUS

Read the review list

Pending means processing is complete and the item is waiting for your decision. Needs Review means the extracted name should be checked. Handwritten means the page needs a careful manual read. Failed means preview or processing could not complete.

The processed count tracks completed items. The status strip below the preview reports the latest action or error.
